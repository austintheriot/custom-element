## Rulings

- Status check: add an aggregate `build-and-test` job that depends on the
  new jobs. This keeps the ruleset unchanged. Cost if wrong: one extra job
  per run.
- Browser and driver pinning (10): rejected. The matrix tests current
  browsers on purpose, and a driver mismatch fails loudly.
- CODEOWNERS and required approvals (11): rejected. The repository has one
  maintainer.
- Counter overflow (32): kept. The PR body states the policy on purpose.
- Type-level guard encoding (33): rejected. It needs a second breaking API
  redesign.
- `docs/superpowers/` stays in the repository and leaves the crate package.
- Example test fixtures stay separate per example. Each example is
  standalone teaching material.
